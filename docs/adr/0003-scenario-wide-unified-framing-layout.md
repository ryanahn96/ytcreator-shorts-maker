# 9:16 화면 프레이밍과 오디오 전환을 개별 Clip이 아닌 전체 Scenario 단위로 통일

기존에는 하나의 숏폼 시나리오 안에서도 Clip마다 화면 레이아웃(화자 클로즈업, 상하 분할, PiP)과 오디오 전환(J-Cut, Hard-Cut, L-Cut)을 개별 지정하도록 되어 있었다. 이를 변경하여 Gemini가 영상 장면에 맞는 초기 `Framing Layout`과 `Audio Transition`을 추천하되, 선택된 레이아웃(크롭·줌 포함)과 오디오 전환 방식은 개별 Clip이 아니라 전체 영상(`Scenario` 전체)에 일관되게 적용되도록 통일했다. 빠른 점프컷이 연속되는 숏폼에서 컷마다 화면 분할 구조나 전환 호흡이 바뀌면 시각적 피로감과 이질감이 커지므로, 시나리오 단위로 통일하고 사용자는 개별 Clip에서 구간(In/Out) 조절과 자막 편집에만 집중하도록 하는 편이 완성도와 편집성 모두에서 우수하기 때문이다.

갱신: 화면 구성을 Scenario 전체에 하나로 두던 부분은 [ADR 0006](0006-per-clip-looks-and-video-fit.md)의 Clip별 Look으로 바뀌었다.
