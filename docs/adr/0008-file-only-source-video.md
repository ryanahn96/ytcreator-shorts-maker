# Source Video는 업로드한 영상 파일만 받는다

ADR 0005는 YouTube URL과 영상 파일 두 가지로 분석을 시작할 수 있게 했다. 그런데 URL로 분석해도 렌더하려면 같은 영상의 MP4를 다시 올려야 했다. 서버에서 YouTube 영상을 받으면 403이 났고, 자막 요청도 자주 429로 막혔기 때문이다. 사용자는 누구나 쉽게 쓰는 화면을 원했고, YouTube URL 입력을 없애고 파일만 올리게 해 달라고 했다. 그래서 YouTube 경로를 통째로 지운다. URL 입력, yt-dlp 메타데이터·자막 수집, YouTube 플레이어 미리보기, 분석 요청의 `youtubeUrl`, 자막 출처 정보, 렌더용 MP4를 다시 올리는 단계가 모두 빠진다. 이제 분석한 파일이 곧 렌더 원본이다. 미리보기는 늘 그 파일로 그리고, 받아쓰기는 늘 Gemini가 한다.

## Considered Options

화면에서만 숨기고 서버의 YouTube 코드는 남기는 안도 있었다. 쓰지 않는 경로를 계속 고쳐 가며 유지해야 해서 고르지 않았다.
