# 파이썬 사전 구간 분할 및 레거시 커스텀 도구 루프를 폐기하고 Gemini 네이티브 에이전틱 비디오 이해로 단일화

기존 파이프라인은 파이썬이 자막을 고정된 후보 구간(`seg_01`~`seg_36`)으로 미리 쪼개고 클립 길이를 `4.5초~18초`로 강제 클램핑한 뒤, 사전 분할된 조각과 스토리보드 타일을 조회하는 4개의 커스텀 파이썬 함수 루프를 거쳐 후보 ID만 고르게 했다. 이 사전 분할·길이 클램핑·커스텀 함수 루프를 전면 제거하고, Gemini의 네이티브 `MediaProcessing.AGENTIC` 모드에 원본 영상, 전체 타임스탬프 대본(`Transcript Word`), 사용자의 `Editorial Prompt`를 전달해 `response_schema`(구조화 출력)로 각 `Scenario`와 `Clip`의 시작 시각(`startSec`)과 종료 시각(`endSec`)을 직접 판단해 반환하도록 단일화했다. 사용자는 프롬프트로 편집 방향만 지시하고 구체적인 컷 경계는 영상을 직접 탐색하는 모델이 결정해야 인위적인 문장 절단과 중복 호출 오버헤드가 사라지기 때문이다.
