# 단일 숏폼 템플릿: 레이아웃 종류를 없애고 헤드라인 + 영상 박스 + 자막으로 통일

ADR 0003은 Framing Layout을 Scenario 단위로 통일하면서 중앙 크롭, 상하 분할, 전체 화면 + 흐림 배경 세 가지 중에서 고르게 했다. 사용자가 상하 분할이 필요 없다고 판단하고 참고 쇼츠(https://www.youtube.com/shorts/ekRd3j8d7eA)를 제시해, 레이아웃 종류를 없애고 모든 숏폼이 하나의 Short Template을 쓰도록 바꿨다. 검은 배경 가운데에 모서리가 둥근 16:9 영상 박스를 두고, 박스 위에 Gemini가 제안하고 사용자가 고칠 수 있는 두 줄 Headline(첫 줄 강조색, 둘째 줄 흰색)을, 박스 안 아래쪽에 노란 자막 한 줄을 얹는다. Clip별 맥락 배너와 카라오케 강조는 없앴다. Framing Layout은 이제 영상 박스에 보일 영역(가로·세로 위치와 확대)만 뜻하며 기본값은 원본 화면 전체이고, Gemini가 초기값을 추천한다. 렌더는 ffmpeg가 크롭한 영상을 박스 크기로 줄여 배경 위에 놓고, ASS 파일이 헤드라인·자막과 박스 모서리를 둥글게 덮는 배경색 조각을 그려 명령 하나와 ASS 파일 하나로 유지한다. 로고와 워터마크는 아직 넣지 않는다.

갱신: 화면 구성을 Scenario 전체에 하나로 두던 부분은 [ADR 0006](0006-per-clip-looks-and-video-fit.md)의 Clip별 Look으로 바뀌었다.
